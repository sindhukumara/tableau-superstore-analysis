# 📊 Tableau Superstore Analysis

## Virtual Tableau Visualization Internship

This repository contains the complete work and deliverables for my **Virtual Tableau Visualization Internship**. The project focuses on analyzing the **Tableau Sample Superstore dataset** and developing meaningful business insights through exploratory data analysis, interactive dashboards, advanced visualizations, data storytelling, and performance optimization using Tableau.

---

## 🎯 Project Objective

The primary objective of this project is to use **Tableau** to transform retail sales data into meaningful and actionable business insights.

The analysis focuses on:

* Understanding sales and profit trends
* Identifying high-performing and low-performing regions
* Comparing product categories and sub-categories
* Analyzing customer segments
* Studying the relationship between discount and profitability
* Identifying products and areas contributing to losses
* Designing interactive dashboards for business decision-making
* Applying advanced Tableau visualization and calculation techniques
* Improving dashboard performance and usability

---

## 📂 Dataset

**Dataset:** Tableau Sample Superstore

The Superstore dataset contains retail transaction information including:

* Orders
* Customers
* Products
* Categories
* Sub-Categories
* Sales
* Quantity
* Discount
* Profit
* Regions
* States
* Cities
* Customer Segments
* Order and Ship Dates

The dataset is used consistently throughout the six-week internship project so that each week's work builds upon the previous analysis.

# 📅 Internship Work

## Week 1 — Exploratory Data Analysis and Insight Generation

The first phase focuses on understanding the Superstore dataset and performing exploratory data analysis in Tableau.

### Key activities

* Dataset exploration
* Variable and field identification
* Data quality checks
* Sales and profit analysis
* Category and sub-category analysis
* Regional analysis
* Customer segment analysis
* Discount vs. profit analysis
* Time-based trend analysis
* Outlier and loss identification
* Initial business insight generation

### Main business questions

1. How are sales and profit changing over time?
2. Which regions generate the highest sales and profit?
3. Which categories and sub-categories perform best?
4. Which products contribute to losses?
5. How does discounting affect profitability?
6. Which customer segments contribute most to the business?

### Deliverable

A professional Word report documenting the complete EDA process, visualizations, findings, and business insights.

---

The planning will include:
